# Plan

Imagineer's backlog and decision history. This folder tracks work on the skill repository, not tasks in applications using it.

- [Now](now.md): current work and near-term validation.
- [Later](later.md): candidate improvements, conditional on evidence.
- [Decisions](decisions.md): concise rationale and changes in direction.

Keep items small. Mark completed work with a date and evidence. Promote a later idea to Now only after a recurring problem justifies it. Avoid turning the plan into another agent instruction manual.
