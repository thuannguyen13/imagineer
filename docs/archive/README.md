# Archive

What is not part of Imagineer today: earlier designs, kept for their research and history, and Build, switched off and kept to be put back. None of it describes Imagineer as it is; the current design is [proposals/inspect-and-build.md](../proposals/inspect-and-build.md).

- [build-parked/](build-parked/): the Build command and its three agents, turned off from 0.4.0 and not installed with the plugin. Its README says how to put them back.

- [skillset.md](skillset.md): the three-skill design (guard, forge, ground), superseded on 2026-11-05. Its failure research (§1) still applies.
- [feature-review-loop/](feature-review-loop/): research, reviews and verification techniques for forge's predecessor. The grading research cites them.
